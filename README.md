# Mohammed Anas Developer Portfolio

A responsive React + Vite portfolio for Mohammed Anas. The project uses plain JavaScript JSX, Tailwind CSS, and Lucide icons.

## Structure

```text
mohammed-anas-portfolio/
├── index.html
├── package.json
├── vite.config.js
├── public/
│   ├── favicon.svg
│   └── robots.txt
└── src/
    ├── App.jsx
    ├── main.jsx
    └── index.css
```

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run serve
```
